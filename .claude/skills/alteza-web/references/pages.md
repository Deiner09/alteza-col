# ALTEZA — PAGES REFERENCE

## Principio

Todas las páginas deben pertenecer al mismo sistema visual.

Reutilizar:

- header
- top bar
- buttons
- product cards
- section headings
- footer
- spacing
- typography
- color tokens

No diseñar cada página como si perteneciera a una marca distinta.

---

# 1. Home

Orden recomendado:

1. Top Bar
2. Header
3. Hero
4. Trending Products
5. Categories
6. Promotional Banner
7. Benefits
8. New Collection
9. Brand Story
10. New Arrivals
11. Blog
12. Newsletter
13. Footer

La Home debe funcionar como experiencia editorial
y también como entrada al catálogo.

# 7. Checkout

Checkout debe minimizar distracciones.

Priorizar:

- claridad
- confianza
- resumen del pedido
- formularios simples
- información de envío
- métodos de pago
- seguridad

No introducir navegación innecesaria.

# 12. Search

- búsqueda
- resultados

- sugerencias
- productos

---

# 13. Account

Áreas:

Profile

Orders

Wishlist

Addresses

Settings

Logout

Mantener el mismo lenguaje visual
aunque la estructura sea más funcional.

---

# 14. Error / 404

Debe sentirse parte de Alteza.

Incluir:

mensaje claro

CTA para volver al inicio

CTA para continuar comprando

No usar una pantalla genérica
del framework.

---

# 15. Empty States

Todos los estados vacíos deben incluir:

mensaje

explicación breve

acción recomendada

Ejemplos:

Carrito vacío

Wishlist vacía

Búsqueda sin resultados

Categoría sin productos

---

# 16. Responsive

Toda página debe revisarse en:

Desktop

Tablet

Mobile

No asumir que una composición desktop
puede reducirse automáticamente.

---

# 17. SEO

Cada página importante debe tener:

title

meta description

semantic headings

canonical cuando corresponda

alt text

URLs claras

---

# 18. Regla

Antes de crear una página nueva:

1. revisar esta referencia
2. revisar PRODUCT.md
3. revisar DESIGN.md
4. revisar componentes existentes
5. reutilizar patrones existentes
