# ALTEZA — COMPONENTS REFERENCE

## Principio

Los componentes deben ser:

- reutilizables
- consistentes
- accesibles
- responsive
- fáciles de mantener

Antes de crear un componente nuevo,
buscar primero si ya existe uno equivalente.

---

## Header

Responsabilidades:

- mostrar logo
- navegación principal
- búsqueda
- cuenta
- favoritos
- carrito

Desktop:

Logo | navegación | acciones

Mobile:

Logo | menú | carrito

Debe mantener una altura visual contenida.

---

## Top Bar

Uso:

- envío gratis
- promociones
- anuncios importantes

Características:

- pequeño
- uppercase
- alto contraste
- discreto

No debe dominar la pantalla.

---

## Hero

Elementos:

- eyebrow
- headline
- supporting text
- primary CTA
- secondary link
- imagen principal

Desktop:

2 columnas.

Texto:

izquierda.

Imagen:

derecha.

La fotografía debe ocupar una zona importante
sin invadir la lectura del texto.
