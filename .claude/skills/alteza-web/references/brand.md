# ALTEZA — BRAND REFERENCE

## Identidad

Alteza es una marca de belleza premium orientada al e-commerce.

Categorías:

- Maquillaje
- Skincare
- Cuidado capilar
- Accesorios

## Personalidad

La marca debe transmitir:

- elegancia
- sofisticación
- feminidad
- confianza
- calidad
- modernidad
- exclusividad

## Lenguaje visual

La marca utiliza:

- tonos crema
- blush
- nude
- dusty rose
- rose-gold
- negro como contraste

## Dirección fotográfica

Las fotografías deben sentirse:

- editoriales
- limpias
- luminosas
- premium
- fotorrealistas

Los productos deben ser protagonistas.

## Referencia estructural

La arquitectura visual toma inspiración de tiendas de belleza premium como BeShop.

No copiar:

- código
- textos
- imágenes
- branding

Solo utilizar como referencia:

- composición
- ritmo
- jerarquía
- experiencia de compra
- organización del contenido

## Regla

Todo componente nuevo debe parecer diseñado
originalmente para Alteza.
